# Prompt: Crib Mattress Porch Swing

Design a crib-mattress porch swing using a 2x4-first strategy with ripped pieces allowed.

Requirements:
- mattress opening sized for approximately 52" x 28"
- clean modern style
- create a structurally sensible base, back, side assemblies, and hanging rails
- prefer 2x4 stock, with ripped pieces allowed for slats/trim/rails
- produce named components for SketchUp
- create scenes for:
  1. base frame top view
  2. front elevation
  3. side elevation
  4. exploded assembly
  5. hanging detail
  6. final assembled perspective
- generate plan-sheet style dimension requirements
- generate optimized cut list
- perform structural validation with explicit notes about mounting assumptions and safe-load caveats

Deliverables:
- design summary
- component breakdown
- scene list
- cut list
- hardware list
- safety notes
