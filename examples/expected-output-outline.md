# Expected Output Outline

A strong response from the agent should roughly include:

1. Design spec
   - overall dimensions
   - fit/clearance assumptions
   - materials

2. Component breakdown
   - base frame
   - supports
   - sides
   - back
   - load-bearing parts

3. Structural review
   - load path
   - sag/racking concerns
   - assumptions about mounting and hardware

4. SketchUp modeling plan
   - components to create
   - scene list
   - naming conventions

5. Plan-sheet rendering plan
   - which views
   - dimension strategy
   - exploded view requirements

6. Cut list
   - rough lumber purchases
   - final cuts
   - rip plan
   - waste notes
