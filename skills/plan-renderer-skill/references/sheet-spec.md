# Sheet Spec

## Default sheet goals

A good woodworking plan sheet should let a builder:
- understand the overall form
- identify the parts
- size the parts correctly
- assemble in the right order
- spot any safety-critical details

## Minimum output set

- top view
- front view
- side view
- exploded view
- detail view where joinery or mounting clarity matters

## Dimensioning rules

- Dimension overall size once clearly.
- Dimension part-critical features where they are easiest to read.
- Avoid duplicating unnecessary dimensions across views.
- Prefer readable, build-relevant dimensions over exhaustive CAD-style annotation.

## Labeling rules

- Use short, repeatable names.
- Match labels to part/component names used in the model and cut list.
- Number repeated slats or rails only when it improves assembly clarity.

## Printable layout notes

- Put overall views first.
- Put exploded and detail views after the primary orthographic views.
- Keep notes compact and shop-friendly.
