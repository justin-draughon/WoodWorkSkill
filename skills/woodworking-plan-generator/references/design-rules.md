# Design Rules

## Core design priorities

1. Buildability
2. Structural sanity
3. Material efficiency
4. Appearance

Do not optimize appearance at the expense of an awkward or fragile build.

## Assembly breakdown heuristic

Break designs into:
- primary structure
- secondary structure
- surfaces / slats / panels
- trim
- hardware / mounting

## Joinery defaults

Unless the user asks otherwise:
- default to screws + glue for practical shop builds
- use pocket holes where hidden utility joinery is acceptable
- use lap or butt-joint framing when appropriate
- reserve advanced joinery for visible or premium builds

## Ask-for-clarification triggers

Ask or clearly note assumptions when any of these are unclear:
- exact width / depth / height
- expected load
- mattress / cushion / appliance size
- indoor vs outdoor use
- wall / ceiling / porch / beam mounting details
- finish expectations vs purely utility build

## Special caution projects

Use more conservative language and assumptions for:
- hanging furniture
- child-related items
- lofted / elevated items
- anything supporting dynamic human load
