# Project Types

## Bench / swing / seating
- Prioritize anti-racking structure.
- Prefer clear front-to-back and side-to-side load paths.
- For hanging versions, require mounting assumptions and hardware notes.

## Bed / crib-size / mattress-based projects
- Start from the actual mattress or cushion dimensions.
- Add fit clearance intentionally; do not guess loosely.
- Do not imply child-safety certification.

## Table / work surface
- Prioritize stiffness, leg bracing, and usable overhangs.
- Call out if span suggests sag risk.

## Shelf / rack / wall-mounted project
- Separate shelf capacity from mounting capacity.
- Require explicit wall or substrate assumptions.

## Outdoor furniture
- Favor drainage, replaceable parts, simple joinery, and corrosion-resistant hardware.
- Call out finish and maintenance assumptions.
