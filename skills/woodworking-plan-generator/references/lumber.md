# Lumber Reference

## Common actual dimensions

Use actual, not nominal, lumber dimensions unless the user explicitly asks otherwise.

- 1x2 -> 0.75 x 1.5 in
- 1x3 -> 0.75 x 2.5 in
- 1x4 -> 0.75 x 3.5 in
- 1x6 -> 0.75 x 5.5 in
- 1x8 -> 0.75 x 7.25 in
- 2x2 -> 1.5 x 1.5 in
- 2x3 -> 1.5 x 2.5 in
- 2x4 -> 1.5 x 3.5 in
- 2x6 -> 1.5 x 5.5 in
- 4x4 -> 3.5 x 3.5 in

## Practical defaults

- Prefer 2x stock for primary load-bearing frames unless the project is clearly light-duty.
- Prefer 1x stock for slats, trim, facing pieces, and light secondary members.
- Prefer sheet goods only when the project clearly benefits from panels or boxed construction.
- Prefer repeated part sizes to simplify builds and reduce mistakes.

## Outdoor default

For outdoor builds, assume:
- exterior-rated fasteners
- weather-tolerant lumber choice
- allowance for movement, drainage, and finish maintenance

## Design simplification rule

When two dimension strategies are close, prefer the one that:
1. reduces lumber variety
2. reduces unique cut lengths
3. avoids awkward rips
4. preserves strength where it matters
