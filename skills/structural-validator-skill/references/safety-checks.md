# Safety Checks

## Review checklist

Check these in order:
1. where the load starts
2. how the load travels through the structure
3. where racking or twist could occur
4. where fastener withdrawal or splitting could occur
5. where mounting failure could occur

## Common failure patterns

- long unsupported spans
- side frames without cross-bracing or triangulation
- screws loaded in withdrawal without backup support
- decorative members treated as structural members
- thin slats spanning too far
- hanging loads concentrated at weak attachment points

## Hanging projects

Always require assumptions for:
- mounting member type
- fastener / lag / bolt type
- number of attachment points
- expected user load
- dynamic loading (swinging, bouncing, shifting)

## Language to use

Prefer phrases like:
- "provisional review based on stated assumptions"
- "requires confirmed mounting details"
- "not an engineering certification"
- "recommend conservative reinforcement"

## Escalation cases

If the project is highly safety-sensitive, say so explicitly. Examples:
- child-related suspended builds
- ceiling-mounted human seating
- elevated sleeping platforms
- long unsupported spans under human load
